# PROJECT CONTEXT

## Project Name

J.A.R.V.I.S

---

# Purpose

Criar um assistente pessoal autônomo para Windows inspirado no conceito do JARVIS do Homem de Ferro.

Não se trata de um chatbot.

Trata-se de um agente inteligente capaz de:

- Observar
- Raciocinar
- Aprender
- Agir

---

# Main Principles

Toda decisão técnica deve priorizar:

1. Modularidade
2. Extensibilidade
3. Baixo custo
4. Funcionamento local
5. Segurança
6. Longo prazo

---

# Deployment

Sistema executado localmente.

Plataforma:

Windows

---

# User

Usuário único.

Todas as preferências e memórias pertencem ao proprietário.

# Skill System

- Descobrir skills

- Atualizar skills

# Autonomy

Objetivo final:
